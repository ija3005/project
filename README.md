#Ritual loop is an interactive visulisation which explores how repeated actions can shape our time, emotion, attention and identity. This project shows this through an animated loop along with a timeline underneath. You input the actions given to see the levels of the emotional state go up or down. The loop also adds in particles to do with the path you tend to go more with. 

#How to run:
Please make sure all files are organised and are present. 

Open index.html and run in a browser or run with live server in visual studio code.
